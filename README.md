## 👨‍💻 Sobre mim

Sou desenvolvedor fullstack com experiência em sistemas de gestão empresarial, APIs REST e aplicações web modernas. Trabalho com backend em PHP e com o ecossistema TypeScript/Next.js, passando por banco de dados relacional, CI/CD, e integrações fiscais (NF-e, CT-e, MDF-e). Gosto de código limpo, testes automatizados e de sistemas que realmente funcionam em produção.

- 🔁 Entusiasta de CI/CD e automação de pipelines
